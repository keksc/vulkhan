# Direwolf asset

Original wolf authored in Blender 5.2.2 for Vulkhan. The model, coat atlas,
rig, animation and previews are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

- `wolf.blend`: editable hairless anatomy, 24-bone rig, looping run action,
  three skinned LODs, coat atlas, Blender camera and lights.
- `wolfCoat.png`: 1024×1024 skin atlas, including bare nose, eyes, mouth, ear
  inset and claw swatches.
- `wolfStudio.png`: stationary, furred capture from the Vulkhan Vulkan studio.
- `wolfPreview.png`, `direwolfCoats.png`, `wolfHairCards.png`,
  `wolfStrands.png` and `wolfRun.gif`: Blender authoring previews. Some older
  preview images show experimental fur approaches and are not runtime output.
- `../../models/wolf.glb`: hairless skin LODs, embedded atlas, rig, run action
  and custom per-vertex fur attributes. Fur is generated by the engine.

The Blender vertex attributes `_VKH_FUR` and `_VKH_FLOW` describe length,
density, lift and comb direction on the skin. The engine uses those attributes
to place strands across the triangle surface, so the GLB contains no hair
cards. See [`docs/wolfFur.md`](../../docs/wolfFur.md) for edit, export and
studio instructions.

Regenerate the source from the repository root with `tools/createWolf.py`;
that script applies the anatomy refinement and exports the skin. Export
existing Blender edits directly by running only `tools/exportWolf.py`.

## October 9 reference matching pass

`matchWolfReferences.py` refines the existing anatomy against the supplied
white-wolf references: broader and higher head, fuller muzzle, straighter
forelegs, larger feet, lower croup, smoother limb transitions, red irises and
smooth inner-ear coloring. It runs as part of `createWolf.py` and preserves
the three LODs, skin weights and engine fur attributes.

`referencePass01.png` through `referencePass04.png` show the Blender review
passes; `referenceHead04.png` is the face close-up. The source remains
hairless. `beforeReferenceMatch/` preserves the previous blend, atlas and GLB.

The revised GLB was checked with `tests/validateWolf.py`. The current engine
capture attempt failed to create a Vulkan window surface, so the earlier
`wolfStudio.png` is **not** a preview of these revisions. Matching the full
furred silhouette remains pending a successful engine preview.
